# Sales Performance & Customer Analytics

## Project Overview

This project analyzes sales performance, profitability, products, customers, and regional trends using a Superstore sales dataset.

The project demonstrates an end-to-end data analytics workflow using Python, MySQL, and Power BI.

## Tools & Technologies

- Python
- Pandas
- NumPy
- MySQL
- Power BI
- Excel
- Git & GitHub

## Project Workflow

Raw Dataset → Data Cleaning → SQL Analysis → Python EDA → Power BI Dashboard → Business Insights

## Key Analysis

- Overall Sales and Profit
- Profit Margin
- Sales by Category and Sub-Category
- Product Performance
- Customer Sales and Profit
- Sales by Region
- Sales Trends over Time
- Segment Analysis

## Power BI Dashboard

The dashboard contains three pages:

### 1. Executive Overview
- Total Sales
- Total Profit
- Profit Margin
- Sales by Category
- Sales by Segment
- Profit by Category
- Sales by Region
- Yearly Sales Trend

### 2. Product Analysis
- Sales by Sub-Category
- Profit by Sub-Category
- Top Products by Sales
- Top Products by Profit
- Category-level analysis

### 3. Customer Analysis
- Sales by Segment
- Profit by Segment
- Sales by Region
- Top Customers by Sales
- Top Customers by Profit
- Customer count by Segment

## Dataset

The project uses the Superstore sales dataset containing 9,994 records and 21 columns.
